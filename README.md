# Sarah & Jack · Pamoja Daima

Wedding website for 19 December 2026 in Bunia, in French and Swahili.

Live site: https://jackmutobu.github.io/SarahAndJ/

## Publishing

GitHub Pages publishes the root of `main`. This repository contains the public website only. Invitation PDFs, planning documents, guest lists and private records are maintained separately.

## Configuration

`assets/js/config.js` controls confirmed venues, contacts, the RSVP service, livestream and other guest services. Empty settings keep the corresponding service unavailable. Response collection must be connected and tested before invitations are distributed.

The invitation QR opens the RSVP section directly at `invites/index.html#rsvp`.

Approved opening photograph, floral wreath, round tree seal, palette and fonts are preserved in `assets/`. Typeface licences are included beside the self-hosted fonts.
